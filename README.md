# 💸 Meiiijas Finance Bot

Telegram-бот для беседы: бросаете в чат доходы и обязательные траты — он считает план месяца, показывает кассовые разрывы и сколько можно тратить в день. Хостится на Vercel (вебхук), данные — в Upstash Redis.

## Команды
| Команда | Что делает |
|---|---|
| `/income 80000 5 Аванс` | доход: сумма, число месяца, название (повторяется каждый месяц) |
| `/bill 25000 1 Аренда` | обязательная трата (каждый месяц) |
| `/balance 12000` | сколько денег на руках сейчас |
| `/spend 450 Кофе` / `/undo` | записать / отменить трату |
| `/plan` | план месяца с эмодзи |
| `/list`, `/del 3` | список и удаление |
| `/reset confirm` | стереть всё |

Можно слать несколько команд одним сообщением (по одной в строке). Суммы: `15000`, `15к`, `1,5к`.

## Запуск
1. **@BotFather** → `/newbot` → получить `BOT_TOKEN`. Затем `/setprivacy` → *Disable* (не обязательно для команд, но удобно), и добавить бота в беседу.
2. Деплой: `npm i -g vercel && vercel` в этой папке.
3. В Vercel → Storage / Marketplace подключить **Upstash Redis** к проекту (переменные подставятся сами).
4. В Vercel → Settings → Environment Variables: `BOT_TOKEN`, `WEBHOOK_SECRET` (любая случайная строка). Опционально `CURRENCY`, `TZ_NAME` (по умолчанию `₽`, `Europe/Moscow`). Затем `vercel --prod`.
5. Зарегистрировать вебхук (PowerShell):
   ```powershell
   $env:BOT_TOKEN="..."; $env:WEBHOOK_SECRET="..."; $env:PUBLIC_URL="https://<проект>.vercel.app"; npm run set-webhook
   ```

Тесты: `npm test`.

## Как считается
- Период — от сегодня до следующего поступления (аванс/зарплата), даже через границу месяца.
- Можно потратить за период = деньги на руках − обязательные платежи с датой до следующего дохода − доля трат «в течение месяца» на эти дни. Будущий доход в расчёт не входит.
- Лимит в день = это / дни до дохода; «сегодня ещё» = дневной бюджет − потрачено сегодня (траты, засчитанные в обязательные «в течение месяца», в лимит не входят).
- Доходы и платежи учитываются после нажатия «Пришло» / «Оплачено»; события не позже даты, на которую задан `/balance`, считаются уже учтёнными.
- Неизрасходованный остаток в день дохода бот предлагает отложить в цель накопления.
- Если по ходу месяца остаток уходит в минус перед платежом, бот пишет, сколько не хватит и когда.
- Один чат = один бюджет (по `chat.id`).
