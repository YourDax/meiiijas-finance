# 💸 Meiiijas Finance Bot

Telegram-бот для беседы: бросаете в чат доходы и обязательные траты — он считает план месяца, показывает кассовые разрывы и сколько можно тратить в день. Хостится на Vercel (вебхук), данные — в Upstash Redis.

## Команды
| Команда | Что делает |
|---|---|
| `/income 80000 5 Аванс` | доход: сумма, число месяца, название (повторяется каждый месяц) |
| `/bill 25000 1 Аренда` | обязательная трата (каждый месяц) |
| `/balance 12000` | сколько денег на руках сейчас |
| `/spend 450 Кофе` / `/undo` | записать / отменить трату |
| `/plan` | план месяца с эмодзи |
| `/list`, `/del 3` | список и удаление |
| `/reset confirm` | стереть всё |

Можно слать несколько команд одним сообщением (по одной в строке). Суммы: `15000`, `15к`, `1,5к`.

## Запуск
1. **@BotFather** → `/newbot` → получить `BOT_TOKEN`. Затем `/setprivacy` → *Disable* (не обязательно для команд, но удобно), и добавить бота в беседу.
2. Деплой: `npm i -g vercel && vercel` в этой папке.
3. В Vercel → Storage / Marketplace подключить **Upstash Redis** к проекту (переменные подставятся сами).
4. В Vercel → Settings → Environment Variables: `BOT_TOKEN`, `WEBHOOK_SECRET` и `CRON_SECRET` (любые случайные строки; без `WEBHOOK_SECRET` бот не принимает апдейты, без `CRON_SECRET` не работают ежедневный дайджест и итоги месяца). Опционально `CURRENCY`, `TZ_NAME` (по умолчанию `₽`, `Europe/Moscow`). Затем `vercel --prod`.
5. Зарегистрировать вебхук (PowerShell):
   ```powershell
   $env:BOT_TOKEN="..."; $env:WEBHOOK_SECRET="..."; $env:PUBLIC_URL="https://<проект>.vercel.app"; npm run set-webhook
   ```

Тесты: `npm test`.

## Надёжность
- **Параллельные правки:** апдейты бота, запросы мини-приложения и cron для одного чата идут под замком в Redis (`finance:lock:<chat>`), поэтому не затирают друг друга.
- **Архив:** при чистке 1-го числа старые траты и разовые пункты не пропадают, а попадают в Redis-список `finance:archive:<chat>` (JSON). Если архив недоступен, чистка пропускается.
- **Заблокированные чаты:** если бот удалён из чата или заблокирован, cron перестаёт туда писать (`finance:inactive`), пока в чате снова не напишут боту.
- **Telegram API:** таймаут 10 с и повтор при `429 Too Many Requests`.

## 📱 Мини-приложение
Все функции бота есть и в виде приложения внутри Telegram: сводка и лимит на день, подтверждение «Пришло / Оплачено», траты (запись, правка, категории, привязка к статьям, поиск), план доходов и платежей, цели, резерв на аренду, транспорт, прогноз и графики, импорт PDF-выписки Т-Банка, ввод обычной фразой, любая команда бота, дайджест и цикл бюджета, промт для ИИ, журнал изменений, сброс данных.

- **Как открыть:** отправь боту `/app` в личном чате и нажми кнопку (или кнопку «Бюджет» в меню чата). Меню ставится автоматически после `/start` или `/app`; для всех чатов сразу — `npm run set-webhook` (нужен `PUBLIC_URL`).
- **Бюджеты бесед:** кнопки web_app в беседах Telegram не разрешает, поэтому приложение открывается из личного чата, а бюджет беседы появляется в переключателе после того, как ты написал в ней боту. Доступ проверяется через `getChatMember`: чужие бюджеты не открываются.
- **Безопасность:** каждый запрос к `/api/app` подписан Telegram (`initData`, HMAC от `BOT_TOKEN`, срок действия 24 часа). Без подписи API ничего не отдаёт.
- **Синхронизация:** правки из приложения сразу видны боту, закреплённая сводка в чате обновляется, о перерасходе бот предупреждает как обычно.
- **Адрес:** берётся из `APP_URL`, затем `PUBLIC_URL`, затем из домена проекта Vercel. Статика лежит в `public/`, API — в `api/app.js`.
- **Импорт выписки:** файл до ~2,5 МБ (лимит тела запроса Vercel 4,5 МБ).

## Как считается
- Период — от сегодня до следующего поступления (аванс/зарплата), даже через границу месяца.
- Можно потратить за период = деньги на руках − обязательные платежи с датой до следующего дохода − доля трат «в течение месяца» на эти дни. Будущий доход в расчёт не входит.
- Лимит в день = это / дни до дохода; «сегодня ещё» = дневной бюджет − потрачено сегодня (траты, засчитанные в обязательные «в течение месяца», в лимит не входят).
- Доходы и платежи учитываются после нажатия «Пришло» / «Оплачено»; события не позже даты, на которую задан `/balance`, считаются уже учтёнными.
- Неизрасходованный остаток в день дохода бот предлагает отложить в цель накопления.
- Если по ходу месяца остаток уходит в минус перед платежом, бот пишет, сколько не хватит и когда.
- Один чат = один бюджет (по `chat.id`).

## Структура кода

- `lib/engine.js` — маршрутизация апдейтов Telegram; реализация в `lib/engine/` (`messages`, `callbacks`, `cards`, `dash`, `documents`).
- `lib/ops.js` — общие операции над бюджетом (удаление, категория, привязка, подтверждение платежа, импорт выписки). Их используют и бот, и мини-приложение (`lib/app.js`), поэтому правило живёт в одном месте.
- `lib/commands.js` — меню команд и нижняя клавиатура личного чата; `/start` обновляет их автоматически.
- `public/` — мини-приложение: `app.js` подключает `js/main.js`; модули `state`, `util`, `ui`, `tabs`, `forms`, `handlers`. `stats.js` — чистые функции (сравнение недель и месяцев, поиск), покрыты тестами.

## Экспорт и размер данных

- В мини-приложении «Траты → ⬇️ CSV» присылает файл в личный чат с ботом (Excel/Google Таблицы). Для этого один раз нужно написать боту `/start`.
- Бюджет чата хранится одним JSON-ключом; запрос к Upstash ограничен примерно 1 МБ. Размер виден во вкладке «Ещё → Объём данных», а при превышении 600 КБ предупреждение попадает в логи Vercel (при сохранении и в cron).
